LHTB terminus-2: 턴별 컨텍스트와 캐시 read / write

x축은 에이전트 턴(API 호출 1회), y축은 그 호출의 prompt 토큰(= 컨텍스트 크기). 막대는 cache read(아래), cache write(위), 잔여 uncached(맨 위)로 쌓여 있고, 점선은 compaction 직후 첫 턴, 삼각형은 verifier 거절 직후 턴입니다. 각 패널 아래의 작은 패널은 같은 턴의 output(completion) 토큰입니다. 막대 위에 마우스를 올리면 턴별 수치가 보입니다.

막대는 각 트라이얼의 마지막 verifier 실행 결과(verifier/reward.txt). 조건별로 묶었고 과제는 색으로 구분합니다. 통과하면 루프가 끝나므로 실행 시간이 3시간보다 짧은 트라이얼은 통과한 것입니다.

  • phases: verifier 가 거절한 횟수(= 이어진 continuation 수). 첫 완료 선언: 에이전트가 처음 task_complete 를 선언한 시점. 명령 턴: 실제로 키 입력을 보낸 턴 수. 비용: 본 호출만(요약 호출 제외), configs/prices.json 의 단가 기준(장문 할증 미적용).

Compaction 직후 prefill(cache write)의 변동성

각 점은 compaction 1회. x = compaction 직후 첫 턴의 cache write 토큰(새 prefix 전체를 새로 써 넣는 양). 세로 막대는 평균, 띠는 ±1 표준편차. 과제 색이 아니라 모델별 그룹으로 묶었습니다.

  • L_before: compaction 직전 턴의 prompt(실효 compaction 한도). L_p: compaction 직후 턴의 prompt. write_c: 직후 턴의 cache write. write_5: 직후 5턴 cache write 합. base: 직전 20턴의 턴당 cache write 중앙값(정상 상태 증분 prefill). summ in/out: 요약을 만든 3회 호출(summary / questions / answers)의 입력·출력 토큰 합. out 직전5턴 / 직후턴 / 직후5턴: compaction 직전 5턴 평균, 직후 첫 턴, 직후 5턴 평균의 output(completion) 토큰.
  • cache write 는 Anthropic 응답의 cache_creation_input_tokens(패치된 harbor 가 기록), OpenAI 는 prompt − cached_tokens 입니다. OpenAI 는 1,024 토큰 이상 prefix 만 128 단위로 캐시되므로 직후 턴에도 시스템 프롬프트 부분은 cache read 로 잡힙니다.
  • stock terminus-2 의 압축 판단은 litellm 로컬 토크나이저 기준이라 Anthropic 모델에서는 L_before 가 명목 임계값의 약 1.5배가 됩니다. optlimit.harbor_agent 로 돌린 조건은 API 가 보고한 prompt 토큰으로 판단하므로 L_before ≈ 설정값입니다.
  • 점수: 각 트라이얼의 result.json 의 verifier_result(마지막 verifier 실행 결과). 중간 점수는 패치된 harbor 의 interim_verifier.jsonl.
